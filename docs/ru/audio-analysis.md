# Анализ аудио

> **Статус:** M6 завершён. Встроенный пакет разбирает контейнеры WAV и PCM,
> читает ID3 и заголовки MPEG-кадров, строит спектрограммы, декодирует
> DTMF/Morse и сообщает о пиках автокорреляции эхо-скрытия. `ffprobe` и SoX
> добавляют покрытие через те же необязательные мосты.

Аудио-плагины — обычные `Analyzer`: получают один артефакт и создают текст,
метаданные, изображения или байты. Спектрограмма — это изображение, поэтому
`bridge.tesseract` может распознать её; строка DTMF/Morse — текстовый артефакт,
который сразу ищет движок флагов.

## Техники

| Область | Покрытие |
|---|---|
| WAV | Заголовок `RIFF/WAVE`, чанки `fmt ` и `data`, дополнительные чанки, PCM/float/extensible, каналы, частота, выравнивание, глубина, число кадров, длительность, байты после RIFF |
| WAV LSB | Один бит каждого PCM-сэмпла, любая битовая плоскость байта, все или выбранные каналы, MSB/LSB |
| MP3 | ID3v2.2/2.3/2.4 (текст, комментарии, метаданные) и ID3v1 |
| MPEG-кадры | MPEG1/2/2.5 Layer I-III, битрейт/частота/режим, число кадров, длительность, потери синхронизации, битые и обрезанные заголовки, смешанные потоки |
| Спектрограмма | Радикс-2 FFT на чистом Python, окно Ханна, настраиваемые FFT/hop, grayscale PNG, низкие частоты внизу |
| Тоны | DTMF через алгоритм Гёрцеля, Morse с адаптивными таймингами и таблицей A-Z/0-9 |
| Эхо | Нормализованные пики автокорреляции в заданных lag/threshold |

Весь встроенный разбор использует стандартную библиотеку; NumPy, FFmpeg и SoX
не обязательны.

## Плагины и опции

| Плагин | Назначение | Основные опции |
|---|---|---|
| `audio.wav` | Чанки, формат, длительность, хвост | нет |
| `audio.wav_lsb` | Битовые плоскости PCM | `bit=1`, `channels="all"`, `order="msb"`, `max_samples=8000000` |
| `audio.id3` | ID3v2/v1 и текст | нет |
| `audio.mp3_frames` | Обход MPEG-кадров и аномалии | `max_frames=200000` |
| `audio.spectrogram` | PNG спектрограммы | `fft_size=1024`, `hop=512`, `max_frames=2000`, `max_seconds=120.0`, `max_samples=8000000`, `dynamic_range_db=80.0` |
| `audio.tones` | DTMF и Morse | `max_samples=4000000`, `dtmf=True`, `morse=True` |
| `audio.echo` | Пики автокорреляции | `max_samples=4000000`, `min_lag=20`, `max_lag=1000`, `threshold=0.25` |
| `bridge.ffprobe` | Метаданные контейнера/потоков | нет |
| `bridge.sox` | Статистика SoX | `mode="stat"` или `"info"` |

```toml
[plugins.options."audio.wav_lsb"]
bit = 1
channels = "all"
order = "msb"

[plugins.options."audio.spectrogram"]
fft_size = 2048
hop = 512
max_seconds = 60

[plugins.options."audio.echo"]
min_lag = 20
max_lag = 500
threshold = 0.3

[plugins.options."bridge.sox"]
mode = "stat"
```

## Примеры

```bash
nvox scan challenge.wav --flag-format 'ctf{}'
nvox scan song.mp3 --flag-format 'pico{}' --no-external --out out/
```

Спектрограмма становится артефактом и встраивается в HTML. При установленном
Tesseract `bridge.tesseract` распознаёт её, и текст возвращается в граф. При
наличии FFmpeg/SoX выполняются `bridge.ffprobe` и `bridge.sox`; их отсутствие
даёт пропуск `requirement`.

## Фикстуры

Все аудиофикстуры создаются стандартной библиотекой в
`tests/fixture_builders.py`. Запуск:

```bash
.venv/bin/pytest -o addopts='' -q tests/test_audio_plugins.py
```

Покрыты WAV-чанки и хвост, LSB и битовые плоскости, ID3/MPEG-аномалии, FFT и
PNG спектрограммы, DTMF, Morse, эхо, а также мосты ffprobe/SoX на поддельных
исполняемых файлах.

## Ограничения

- LSB требует целочисленный PCM с целыми байтами. Float, сжатый и ADPCM WAV
  дают пропуск.
- MP3-анализ читает теги и заголовки кадров, но не декодирует звук в PCM;
  для LSB/спектрограммы нужен WAV. FFmpeg — необязательный декодер.
- Спектрограмма минимальна: без подписей осей, цветовых карт и зума.
- DTMF/Morse — эвристики для чистых CTF-фикстур; шум и нестандартные тайминги
  могут требовать ручной проверки.
- Эхо-детектор сообщает пики автокорреляции, а не декодированный payload.
- `ffprobe`/SoX необязательны; `nvox doctor` показывает наличие.
