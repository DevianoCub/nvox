# Nvox

Nvox — модульный фреймворк криминалистического анализа и стеганографии для
изображений, аудио и произвольных файлов. Передайте ему файл и, при
необходимости, формат флага; Nvox обойдёт граф артефактов — битовые плоскости
LSB, метаданные, встроенные файлы, декодированные данные — и найдёт совпадения
или соберёт артефакты для дальнейшего разбора, сохраняя цепочку происхождения.

```bash
nvox scan photo.png --flag-format 'ctf{}'
```

## Принципы

1. **Граф артефактов, а не контрольный список.** Каждый результат становится
   артефактом, который анализируется снова. Флаг в
   `base64(zlib(LSB(пиксели)))` находится тем же конвейером, что и в исходном
   изображении.
2. **Всё является плагином.** Анализаторы, извлекатели и декодеры — плагины.
   Внешние программы подключаются декларативно. Хуки позволяют менять поведение
   ядра.
3. **Сначала встроенные средства, внешние инструменты необязательны.** Nvox
   работает на чистом Python. Если установлены `exiftool`, `steghide`,
   `binwalk`, `zsteg` и другие, их мосты добавляют покрытие автоматически.
   Отсутствующая программа фиксируется как пропуск и не прерывает скан.
4. **Доказательства неизменяемы.** Входные файлы открываются только для
   чтения; результаты пишутся в отдельный каталог, каждый артефакт адресуется
   по SHA-256.
5. **Ограниченный анализ.** Глубина, тайм-ауты, размер артефактов, коэффициент
   распаковки архивов и число потоков настраиваются и соблюдаются.
   `scan.isolation = "process"` добавляет изоляцию процессов с жёстким
   тайм-аутом для подходящих Python-плагинов. Это не ОС-песочница; см.
   [Ужесточение](hardening.md).

## Статус

**0.1.0** — первый помеченный релиз. Все этапы M0-M7 завершены.

| Этап | Содержание | Статус |
|---|---|---|
| M0 | Основа проекта, конфигурация, `nvox doctor` | готово |
| M1 | Ядро: артефакты, реестр, планировщик, хуки | готово |
| M2 | Движок флагов, декодеры, XOR, происхождение | готово |
| M3 | Глубокий анализ изображений и стеганография | готово |
| M4 | CLI, HTML-отчёт, TUI | готово |
| M5 | Мосты к внешним инструментам, песочница плагинов | готово |
| M6 | Аудио и общие файлы | готово |
| M7 | Ужесточение, документация, релиз 0.1.0 | готово |

Команды: `nvox scan`, `nvox doctor`, `nvox plugins list|info|dirs`,
`nvox extract`, `nvox report`, `nvox tui`.

`nvox scan` работает и без формата флага: тогда он записывает полный отчёт об
артефактах в JSON/CSV и HTML. Внешние инструменты необязательны; их отсутствие
не прерывает скан. После 0.1 добавлены `generic.binary_tokens` для смешанных
`.bin` и `scripts/check-corpus.py` для регрессионных прогонов на реальных
CTF/forensic-задачах.

## Правовое использование

Используйте Nvox только для файлов, которыми вы владеете или которые
разрешено исследовать: CTF-задания, материалы инцидентов, образцы malware в
контролируемой лаборатории или собственные данные.
