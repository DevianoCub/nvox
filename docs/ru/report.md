# HTML-отчёты и TUI

> **Статус:** M4 завершён. `nvox scan` по умолчанию пишет `report.html`,
> `nvox report` пересобирает сохранённый запуск без сканирования, `nvox tui`
> открывает интерфейс Textual.

## Автономный HTML-отчёт

Каждый скан пишет `out/report.html` рядом с `findings.json`. Отключение —
`--no-html`; пересборка без плагинов:

```bash
nvox scan challenge.png --flag-format 'ctf{}' --out out/
nvox report out/
nvox report out/findings.json --out /tmp/triage.html
nvox report out/ --open
```

HTML встраивает CSS, JavaScript и данные превью. Нет зависимостей от CDN,
шрифтов, таблиц стилей или изображений, поэтому файл открывается на машине без
сети.

### Содержимое

| Раздел | Данные |
|---|---|
| Сводка | Файлы, артефакты, находки, пропуски, запуски плагинов, время, форматы |
| Находки | Фильтруемые карточки по поверхностям, уверенность, смещение, контекст, граф происхождения |
| Доказательства | Путь, SHA-256, MIME, размер, число артефактов |
| Дерево артефактов | Родитель/потомок, производитель, вид, размер, глубина, параметры, превью |
| Пропуски | Плагин, причина, артефакт |
| Фильтры | Находки по тексту/уверенности; артефакты по имени/производителю/виду/хешу |

Текстовые артефакты показываются до 4 000 символов; изображения и аудио
встраиваются как data URI до 2 MiB. Большие payload описываются размером.
Предел меняется `--max-preview-bytes` у `nvox report`. Все строки
HTML-экранируются. Payload читается из хранилища рядом с `findings.json`; если
JSON перенесён без `artifacts/`, метаданные и находки отображаются, а превью
помечаются недоступными.

## Textual TUI

```bash
uv sync --extra tui
```

```bash
nvox tui --report out/
nvox tui challenge.png --out out/
nvox tui
```

Слева дерево артефактов, справа вкладки:

- **Preview** — метаданные, текст/hex, размеры PNG;
- **Findings** — флаг, уверенность, поверхность, цепочка и доказательство;
- **Plugins** — флажки плагинов, all/none, путь доказательства, формат флага и
  регулярное выражение.

| Клавиша | Действие |
|---|---|
| `s` | Сканировать путь из поля доказательства |
| `r` | Перезагрузить отчёт из `--report` |
| `q` | Выход |

TUI использует тот же движок, хранилище и мягкие пропуски. Отсутствие внешних
инструментов не прерывает скан. Результаты пишутся в `--out` и открываются
снова через `nvox report`.

## Вывод терминала

Интерактивный скан показывает строку прогресса Rich с текущим файлом и
счётчиками. Затем находки группируются по поверхности и цепочке:

```text
Findings (2)
├── text (1)
│   └── evidence
│       └── ctf{direct} high offset 0x10 · evidence/note.txt
└── bitstream (1)
    └── image.lsb -> decoder.base64
        └── ctf{hidden} medium offset 0x0 · evidence/photo.png
```

Для `--json` и неинтерактивного вывода прогресс отключён, stdout остаётся
валидным JSON.
