# Переход на 0.1.0

> **Статус:** 0.1.0 — первый помеченный релиз. `nvox.api.API_VERSION` остаётся
> `1`; поверхность импорта и модель артефактов не изменились относительно
> снимков M6.

Большинство пользователей могут обновить checkout без изменений в коде. Ниже —
отличия от снимков до 0.1.

## Конфигурация

| Параметр | Поведение 0.1.0 |
|---|---|
| `scan.isolation` | Новый. `"thread"` по умолчанию; `"process"` для подходящих Python-плагинов |
| `scan.max_depth` | Без изменений |
| `scan.timeout` | Кооперативный тайм-аут; теперь также дедлайн родителя в process-режиме |
| `scan.max_artifact_bytes` | Без изменений |
| `scan.jobs` | Без изменений; `0` = по потоку на CPU |
| `generic.archive.max_ratio` | Применяется к ZIP и gzip/bzip2/xz |
| `generic.archive.max_file_bytes` | Также ограничивает фактическое расширение потока |

```toml
[scan]
isolation = "thread"
max_depth = 4
timeout = 120
max_artifact_bytes = 67108864
jobs = 0
```

`nvox doctor --json` теперь содержит `config.limits.isolation`. Потребители
JSON, читающие именованные ключи, не затронуты.

## CLI

```bash
nvox scan evidence.bin --isolation thread   # по умолчанию
nvox scan evidence.bin --isolation process  # убивать зависшие плагины
```

Вывод по умолчанию, схема отчёта, коды выхода и `--json` не изменились.
Process-режим добавляет небольшую стоимость запуска на каждый плагин.

## Архивы

Члены с высокой степенью сжатия выше `max_ratio` теперь пропускаются, а не
разворачиваются. Легитимный архив может поднять лимит:

```toml
[plugins.options."generic.archive"]
max_ratio = 5000
```

Проверка выполняется после ограниченного чтения, поэтому ловит и неверные
метаданные размера. Пропуски видны в `archive/summary`.

## Плагины

Контракт не изменился: `nvox.api`, `API_VERSION = 1`, родительские хеши,
производитель, глубина, пропуск `requirement` и песочница команд.

Новое в 0.1.0:

- шаблоны `examples/plugins/template.py` и
  `examples/plugins/command-template.toml`;
- тесты `tests/test_plugin_conformance.py`;
- необязательная изоляция процессов для встроенных, локальных и entry-point
  Python-плагинов.

Проверьте:

1. `name` уникально и валидно, `api_version` не выше `1`;
2. `targets` непуст, `run` соблюдает `ctx.max_artifact_bytes`;
3. отсутствующие требования дают `ctx.skip` или объявлены в `requires`;
4. плагин детерминирован, не использует сеть и не пишет вне артефактов;
5. короткий smoke-тест проходит через реестр, как в тесте шаблона.
