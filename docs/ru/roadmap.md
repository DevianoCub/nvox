# План развития

Этапы последовательны: следующий начинается только когда текущий зелёный
(`pytest`, `ruff check`, `ruff format --check`, `mypy`) и выполнены критерии
приёмки.

## M0 — Основа проекта (готово)

- [x] Проект `uv`, layout `src/`, сборка hatchling, скрипт `nvox`
- [x] Python 3.12+, dev-группа, extras `image`/`tui`/`docs`
- [x] `nvox --version`, `--config`, оболочка Typer + Rich
- [x] Поиск `nvox.toml` (`--config`, cwd, XDG) с валидацией
- [x] Реестр внешних инструментов с категориями, атрибутами Nix и этапами
- [x] `nvox doctor` (обычный, `--verbose`, `--json`)
- [x] Тесты конфигурации и CLI, настройка ruff/mypy
- [x] Английское дерево документации и зарезервированный `docs/ru/`

Приёмка: `uv run nvox doctor` работает на чистой машине; ошибки конфигурации —
чистые сообщения без traceback.

## M1 — Ядро (готово)

- [x] Приём доказательств: снимок только для чтения, SHA-256, размер, MIME
- [x] Хранилище артефактов по содержимому с лимитами и зеркалом на диск
- [x] Виды артефактов: `bytes`, `text`, `image`, `audio`, `archive`, `meta`
- [x] Базовые классы плагинов в `nvox.api`; декоратор регистрации
- [x] Реестр: встроенные, локальные каталоги, entry points, TOML-плагины
- [x] Планировщик: приоритеты, тайм-аут, глубина/размер, потоки
- [x] Дедупликация по (хеш, плагин, опции) и множество посещений
- [x] Хуки: `pre_ingest`, `on_artifact`, `post_scan`, `on_finding`
- [x] `nvox plugins list|info|dirs`, `nvox extract`
- [x] Пропуски с причинами; структурированные события (`logging` и `on_event`)
- [x] Очистка устаревших `*.tmp`; артефакты доказательств не удаляются

Приёмка: цепочка `bytes -> text -> match` работает end to end;
`tests/test_engine.py` покрывает дедупликацию, глубину, тайм-аут, пропуски
`requirement`/`disabled`, ошибки плагинов и хуки; `tests/test_registry.py` —
обнаружение и TOML; `tests/test_cli_plugins.py` — инспекцию и извлечение.

## M2 — Движок флагов (готово)

- [x] Компилятор `prefix{}` с несколькими форматами и `-i`
- [x] Сырые регулярные выражения (`--flag`), `--min-length`/`--max-length`
- [x] Поверхности: сырой payload, ASCII/UTF-16LE/BE, текст, метаданные, LSB PNG
- [x] Декодеры: base64/base64url/base32/base85/hex/url/rot13/rot47/reverse/
      gzip/zlib/bzip2/xz
- [x] Рекурсивное декодирование с бюджетом глубины и посещениями
- [x] Перебор однобайтового XOR с оценкой печатного текста
- [x] Находки с контекстом, кратчайшей цепочкой, уверенностью; JSON
- [x] Коды выхода и `nvox scan`, включая рекурсивные каталоги
- [x] Минимальные `image.exif` и `image.lsb` для фикстур
- [x] Фикстуры: хвост, base64, вложенный zlib, UTF-16, EXIF base64, XOR, LSB

Приёмка: все фикстуры находятся end to end; отчёт объясняет каждую цепочку;
`ruff`, `mypy` и полный набор тестов зелёные.

Примечание: полные метаданные (XMP/IPTC/ICC/чанки PNG/сегменты JPEG),
плоскости 1-8 и произвольные порядки бит остались на M3. Потоковые сканы и
перекрывающиеся окна — работа M5/M7; артефакты M2 в памяти.

## M3 — Глубокий анализ изображений (готово)

- [x] EXIF/XMP/IPTC/ICC; чанки PNG (`tEXt`, `zTXt`, `iTXt`, CRC, прочие)
- [x] Сегменты JPEG (`APPn`, `COM`), расширения GIF, основы BMP/TIFF
- [x] Хвост/префикс, обнаружение полиглотов
- [x] Плоскости 1-8 x каналы x порядок бит x построчно/поколоночно
- [x] Автоматическое обнаружение zlib/deflate в битовых потоках
- [x] Аномалии палитры и альфы, фильтры каналов, изображения плоскостей
- [x] Поиск встроенных файлов по магии и карвинг
- [x] Необязательные QR/OCR (мосты M5: `bridge.zbar`, `bridge.tesseract`)

Приёмка: по фикстуре на технику в `tests/test_image_deep.py`; PNG 12 MP
укладывается в 48.7 с при бюджете 120 с; таблица покрытия и ограничения — в
[Анализе изображений](image-analysis.md).

## M4 — UX (готово)

- [x] Вывод Rich с прогрессом и группировкой находок
- [x] Автономный HTML: дерево артефактов, превью, находки, происхождение,
      фильтры
- [x] Textual TUI: дерево, превью, находки, переключатели плагинов

Приёмка: реальный образец разбирается end-to-end из терминала, HTML
открывается без сети. См. [Отчёты и TUI](report.md).

## M5 — Мосты и декларативные плагины (готово)

- [x] `core/sandbox.py`: rlimits, завершение группы процессов, лимиты вывода
      для команд и мостов
- [x] Мосты: exiftool, zsteg, steghide, stegseek, outguess, pngcheck, binwalk,
      foremost, StegSolve, zbar, tesseract. StegSolve требует headless-команду,
      иначе пропуск.
- [x] Ужесточение TOML-плагинов: песочница, минимальное окружение,
      автоматические требования, безопасный сбор файлов, лимиты
- [x] Интеграция `doctor` и аккуратные пропуски `requirement`
- [x] `shell.nix` и установщик Arch (сделано раньше; `jphide`, `jpseek`,
      `stegdetect` без пакетов)
- [x] Devshell `flake.nix` со всеми необязательными инструментами

Приёмка: с инструментами всё работает; без них каждый мост пропускается с
причиной, скан завершается. Тесты используют поддельные исполняемые файлы, а
отдельный тест удаляет все требования.

## M6 — Аудио и общие файлы (готово)

- [x] Аудиометаданные (ID3, ffprobe), LSB WAV, аномалии MP3-кадров
- [x] Спектрограммы и необязательный OCR через существующий конвейер
- [x] DTMF и Morse, эвристики эхо-скрытия, мост sox
- [x] Общее: энтропия, строки в нескольких кодировках, карвинг, рекурсия

Приёмка: аудио- и рекурсивные архивные фикстуры проходят; аудиопакет
использует те же контракты, что и изображения.

Приёмка: чек-лист релиза 0.1.0 выполнен; нет известных падений на некорректном
